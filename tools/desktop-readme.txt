OPENING IT
  1. Double-click  index.html  — that is the RoboCL homepage.
  2. Read "what is inside", then click  Start free  to create an account
     (username + password only — no email needed).
  3. After that you land on the dashboard and every page is open.

  Online version (works on your phone too):
  https://wenxin677.github.io/international-public-law-study-hub/

WHAT IS INSIDE
  index.html      Homepage: tour, how it works, FAQ, sources
  signin.html     Create an account / sign in
  dashboard.html  Your progress, streak, XP, chapters, continue studying
  learn.html      33 lessons: objectives, key points, quotes, flashcards, notes
  quiz.html       238 questions — per lesson, per chapter, or mixed 10
  teacher.html    RoboCL, the AI teacher (it shows its thinking, then answers with page numbers)
  library.html    Read the textbook page by page + the reference PDFs + real page samples
  glossary.html   193 Khmer–English legal terms
  about.html      Who made it and how
  admin.html      Owner page: the accounts and sign-ins recorded on this computer
                  (ask Sok Panha for the owner code — it is not stored in the files)

TIPS
  • Switch Khmer / English with the buttons at the top right (there are only two).
  • Ctrl+K (Cmd+K on Mac) searches lessons, terms and pages from anywhere.
  • In quizzes press 1–4 to answer and Enter for the next question.
  • Your progress, notes and quiz scores are saved in this browser.
  • Ctrl+P on a lesson prints it as study notes.
  • The AI teacher only reads the three source documents — if it cannot find
    something it says so instead of inventing an answer.

ABOUT THE ACCOUNT
  • Your password is never stored as text. The browser turns it into a
    PBKDF2 hash and keeps only that.
  • Accounts created here live in this computer's browser. To see them, open
    admin.html and enter the code. To collect sign-ups from other people's
    devices, the owner connects a free Supabase project (see READ ME in the
    GitHub repository, section "Accounts").
